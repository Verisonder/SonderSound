# Models in app/src/main/assets

| File | What | From |
|---|---|---|
| `melspectrogram.tflite` | audio → mel spectrogram | openWakeWord v0.5.1 release |
| `embedding_model.tflite` | mel → 96-d speech embedding | openWakeWord v0.5.1 release, a re-implementation of Google's `speech_embedding` |
| `background.f32` | mean embedding of ordinary speech | generated by `tools/replay/replay.py --background` |

## Licence — must be settled before a public release

openWakeWord's README states its code is Apache-2.0 but its **pre-trained models are
CC BY-NC-SA 4.0**. The embedding model is a re-implementation of Google's `speech_embedding`
(TF Hub, Apache-2.0).

CC BY-NC-SA is not compatible with shipping inside a GPL-3.0 app. Options:

1. Convert Google's original `speech_embedding` (Apache-2.0) to TFLite and replace
   `embedding_model.tflite`, and compute the mel spectrogram in Kotlin instead of
   `melspectrogram.tflite`.
2. Ask the openWakeWord author for a licence exception for these two files.

Until then these files are fine for test builds and must not go into a published release.
